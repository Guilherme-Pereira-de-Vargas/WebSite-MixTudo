# MixTudo

Sistema web de gerenciamento de uma loja de variedades, desenvolvido em PHP com banco de dados MySQL. Permite cadastrar, consultar, editar e excluir clientes, produtos e categorias, centralizando as informações da loja em uma interface de navegação simples.

O catálogo reúne nome, descrição, preço, código de barras e quantidade em estoque dos produtos, relacionando cada item à sua categoria. O projeto utiliza HTML, CSS e JavaScript na interface e organiza o código em modelos, controladores e visualizações.
